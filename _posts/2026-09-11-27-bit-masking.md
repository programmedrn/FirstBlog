  ## Bit Masking
  상태값 업데이트와 비트마스킹을 통한 최적해 찾기

제목은 Bit Masking이지만 실상은 최적해를 찾기 위해 상태값을 업데이트하는 방법일 뿐이다. n개 노드가 있을 때 각 노드를 1부터 n까지 번호를 매기자. 풀어야 할 문제는 모든 노드를 방문했을 때 어떤 상태값의 최적값을 찾는 것이다. 이 때 n개 노드의 방문 여부를 DFS로 풀면 2^n까지 늘어나겠지만 결국 방문했을 때 최적인 경우를 찾는 것이라면, 즉 방문 순서와 관계없이 방문한 결과값은 동일할 때 최적을 찾으면 된다. 예를 들어 1 -> 2 -> 3 -> 4 일 때와 1 -> 3 -> 2 -> 4일 때 마지막 위치는 4로 동일하고 방문한 결과도 1,2,3,4 이지만 택한 경로에 따라 비용이 다를 수 있다. 이 비용의 최적해를 구할 때 1, 2, 3, 4를 방문했다는 기록으로 bit masking을 쓰고 bit masking 단위로 순회하며 최적해만 업데이트 한다면 자연히 같은 bit masking값에 불리한 비용인 경우는 향후 탐색에 제외되는 결과를 가지므로 최적해 찾기에 optimizing이 될 수 있다.

문제를 예로 들면 외판원 문제이다. int[][] cost로 노드 a에서 b로 갈 때의 비용이 cost[a][b]로 주어지고 외판원이 모든 노드를 방문해야 한다고 하자. 이때 관리해야 할 Optimized된 상태란 여태껏 어느 노드들을 방문했으며 현재 어느 위치에 있으며, 그 때의 최소비용이다. 이 값을 이제 int[][] dp로 저장하고 dp = new int[1 << n][n] 으로 지정하면 dp[bitmask][now]의 값은 bitmask만큼 방문했으며 현재 now 위치에 있을 떄의 최소 비용값으로 둘 수 있다. 따라서 매번 모든 가능한 경로를 DFS 할 필요 없이 각각에서 최소 비용인 거리만 기억하고 탐색하면 된다.  
아래는 마지막 복귀까지의 비용을 계산하는 코드이다.

```java
int dpMask(int[][] cost, int n){
  int FULL = (1 << n) - 1;
  int INF = Integer.MAX_VALUE;
  int[][] dp = new int[1<<n][n];
  for(int[] row : dp) Arrays.fill(row, INF);
  dp[1][0] = 0;

  for(int mask=0;mask<FULL;mask++){
    for(int now=0;now<n;now++){
      if(mask & (1 << now) == 0) continue; // 방문한 적 없는 곳이 현재 위치일 수 없음
      if(dp[mask][now] == INF) continue; // 아직 계산 안 됨

      for(int j=0;j<n;j++){
        if(mask & (1 << j) != 0) continue; // 이미 방문한 곳
        int next = mask | (1<<j);
        dp[next][j] = Math.min(dp[next][j], dp[mask][now] + cost[now][j]);
      }
    }
  }
  int answer = INF;
  for(int i=0;i<n;i++) answer = Math.min(ans, dp[FULL][i] + cost[i][0]); // 모두 방문한 상태에서 0번 노드로 복귀까지 포함
  return answer;
}
```
