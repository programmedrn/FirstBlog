위상 정렬 알고리즘은 방향성이 있는 그래프가 있고 각 노드가 작업이라고 볼 때 수행하는 데에 제약이 들어오는 간선 수만큼 있어서 해당 노드가 수행되려면 해당 노드로 진입하는 간선들의 출발점인 노드들을 먼저 수행해야 하는, 의존성 작업 스케줄링에 사용하는 알고리즘이다.  
각 노드가 출발점이며 각각의 도착점이 정리된 그래프, List<Integer>[](혹은 int[][]) graph가 존재하며 총 노드의 개수 n, 각각의 노드가 가진 차수(진입하는 간선의 수)가 정리된 int[] indegree가 주어질 때
```java
public List<Integer> topologySort(List<Integer>[] graph, int[] indegree, int n){

  Deque<Integer> dq = new ArrayDeque<Integer>();
  for(int i=0;i<n;i++) if(indegree[i] == 0) dq.offer(i);

  List<Integer> order = new ArrayList<Integer>();
  while(!dq.isEmpty()){
    int now = dq.poll();
    order.add(now);
    for(int target : graph[now]){
      if(--indegree[target] == 0) dq.offer(target);
    }
  }
  return order;
}
```

만약 order가 모든 노드를 처리하지 못했다면(order.size() < n) 처리되지 않고 남은 노드들은 진입 차수가 0이 되지 못했다는 뜻이며 노드들이 서로를 선행 조건으로 갖고 있음을 의미한다. 그래프 내 사이클이 존재한다는 뜻이다.  
위의 코드는 작업 순서에 의미를 두지 않아 선입선출의 기본을 따르지만 우선순위기 필요하다면 deque 대신 priority queue를 쓰면 된다.
