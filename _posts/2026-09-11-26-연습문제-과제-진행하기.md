과제명, 과제 시작 시간, 과제 소요 시간이 묶음으로 담겨있는 목록 String[][] plans가 주어지고 과제는 반드시 과제 시작 시간에 시작하며 과제 소요시간만큼(분)이 소요된다. 과제가 완료되지 않았을 때 다음 과제가 시작하면 수행 중이던 과제는 미루고 과제 시작 시간에 맞춰 새 과제를 시작한다. 다음 과제 시작까지 시간이 남고 미완인 과제가 남아있다면 최근에 과제에 들어간 것부터 이어서 수행한다. 과제 시작시간과 과제 끝나는 시간이 겹치면 과제가 끝난 것으로 본다. 가장 먼저 끝난 과제명부터 마지막까지 나열된 String[] answer를 반환하는 문제. 다만 plans가 과제 시작 시간 기준으로 정렬되지 않았을 수 있으며 과제 소요시간은 100을 넘지 않고 과제 시작 시간은 00:00부터 23:59 까지이다.

우선 plans를 과제 시작 시간 단위로 정렬하고 다음 과제 시작시간까지를 검토하여 미완인 과제는 stack에 과제를 넣고 시간이 남으면 stack에서 꺼내서 수행하는 방식으로 구상했다. 구현은 조금 오류가 있었다.
```java
import java.util.Deque;
import java.util.ArrayDeque;
import java.util.Arrays;

class Solution {
    public String[] solution(String[][] plans) {
        
        int len = plans.length;
        String[] answer = new String[len];
        int answerPointer = 0;
        
        Deque<int[]> stack = new ArrayDeque<int[]>();
        
        Arrays.sort(plans, (a, b) -> a[1].compareTo(b[1]));
        for(int i=0;i<len-1;i++){
            int gap = toMinute(plans[i+1][1]) - toMinute(plans[i][1]);
            int todo = Integer.parseInt(plans[i][2]);
            int free = gap - todo;
            if(free < 0){
                stack.push(new int[]{i, todo - gap});
                continue;
            }
            answer[answerPointer++] = plans[i][0];
            while(!stack.isEmpty() && free > 0){
                int[] postponed = stack.peek();
                if(postponed[1] <= free){
                    answer[answerPointer++] = plans[postponed[0]][0];
                    free -= postponed[1];
                    stack.pop();
                } else{
                    postponed[1] -= free;
                    free = 0;
                }
            }
        }
        answer[answerPointer++] = plans[len - 1][0];
        while(!stack.isEmpty()){
            answer[answerPointer++] = plans[stack.pop()[0]][0];
        }
        
        return answer;
    }
    
    public int toMinute(String time){
        return Integer.parseInt(time.substring(0, 2)) * 60 + Integer.parseInt(time.substring(3, 5));
    }
    
}
```

구현에서 어려웠던 것은 Arrays.sort의 사용법이었다. (a, b)를 넣었을 때 a가 작으면, compareTo가 음수를 반환한다고 한다. 그러니까 수직선 상에 왼쪽에 있는 것이 왼쪽이니까(오름차순) 음수인 셈. 쓸 때도 (a,b) -> a.compareTo(b)로 쓰고 직접 식을 써야 한다면 (a, b) -> {if(a.equals(b)) return 0; if (a<b) return -1; return 1;} 으로 하면 오름차순 정렬이 된다. 또한 Deque에서 pop, peek, push를 기억하자.
