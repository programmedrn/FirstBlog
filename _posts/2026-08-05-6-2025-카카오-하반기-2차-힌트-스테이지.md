각 스테이지별 힌트 사용 개수에 따른 비용이 주어지고  
각 스테이지별 힌트를 구매할 경우의 비용과 몇 스테이지의 힌트를 주는지에 대한 정보가 주어진 상태에서  
가장 적은 비용으로 스테이지 전체를 통과한 때의 비용을 구하는 문제였다.

DFS라는 것은 쉽게 알 수 있었지만 문제는 힌트의 구매 상태를 어떻게 관리할 것인가 하는 문제였다.  
여기서 백트래킹에 대해 알게 됐는데 상태를 업데이트한 다음 DFS를 이어가고 이전 재귀로 빠져나오면서 상태를 되돌려 놓는 방법이다. 그리고 그 이후 힌트를 구매하지 않은 경우에 대한 DFS를 다시 탐색하게 한다.  
전체 코드는 이렇다.
```java
class Solution {
    
    public int maxStage = 0;
    public int STAGE_LIMIT = 16;
    public int[] hintCountsOnStage = new int[STAGE_LIMIT+1];
    int answer = 0;
    
    int[][] costs;
    int[][] hints;
    
    public int solution(int[][] cost, int[][] hint) {
        
        for(int i = 0;i<=STAGE_LIMIT;i++){
            hintCountsOnStage[i] = 0;
        }
        
        maxStage = cost.length;
        answer = maxStage * 1100000 + 1;
        
        costs = cost;
        hints = hint;
        
        int startStage = 1;
        int startCost = 0;
        
        deal(startStage, startCost);
        
        return answer;
    }
    
    public int buyHint(int stage){
        int[] boughtHints = hints[stage-1];
        int fee = boughtHints[0];
        int len = boughtHints.length;
        // if(boughtHints.length == 1) return;
        for(int i=1;i<len; i++){
            hintCountsOnStage[boughtHints[i]]++;
        }
        return fee;
    }
    public int clearHint(int stage){
        int[] boughtHints = hints[stage-1];
        int fee = boughtHints[0];
        int len = boughtHints.length;
        // if(boughtHints.length == 1) return;
        for(int i=1;i<len; i++){
            hintCountsOnStage[boughtHints[i]]--;
        }
        return fee;
    }
    
    
    public void deal(int stage, int beforeCost){
        if(beforeCost >= answer) return;
        
        int MAX_HINT_LIMIT = Math.min(hintCountsOnStage[stage], maxStage - 1);
        int stageCost = costs[stage-1][MAX_HINT_LIMIT];
        
        if(stage == maxStage){
            int challenge = beforeCost + stageCost;
            if(challenge < answer){
                answer = challenge;
                return;
            }else{
                return;
            }
        }
        
        int hintFee = buyHint(stage);
        // Buying
        deal(stage + 1, beforeCost + stageCost + hintFee);
        clearHint(stage);
        
        if(hintFee != 0){
            // Not Buying
            deal(stage + 1, beforeCost + stageCost);
        }
    }
}
```

풀이 과정 중 헷갈렸던 것은 의외로 백트래킹 자체가 아니라 최소, 최대값과  
힌트 사용 수에 제한이 걸려있다는 점이었다.  
배열에서 이번 스테이지에서 사용할 index는 직관적으로 스테이지1에 stage = 1을 부여함으로 보기 좋게 처리 됐다.

재밌었던 것은 hint 비용이 0인 경우에 대한 처리(무조건 힌트를 구매)  
hint가 비용만 발생하고 내용물이 없는 경우에 대한 처리였다.

전체적으로 메모리 비용 감소를 위해 참조와 복사를 신경쓰며 코딩해서 java 감각을 다시 되새기게 해 준 문제였다.
