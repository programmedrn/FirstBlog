일정 차질에 연연하지 말고 "오늘 7시간을 무엇으로 채우느냐"만 생각하세요.

1일차에 진행했어야 할 **초기 문서화/저장소 세팅**과 2일차의 핵심 목표인 '프로젝트 스캐폴딩(기본 뼈대 구축) 및 첫 도커화'를 결합한 Day 2 실행 타임라인(09:00 ~ 17:00)입니다.

---

### 09:00 ~ 10:00 (1시간) | [트랙 A] 코딩테스트: Java 자료구조 활용 (Set / Map)

목표: Java의 `HashSet`, `HashMap`을 활용해 $O(1)$ 접근 패턴을 연습합니다.

1. **문제 풀이 (40분)**
* **프로그래머스 Lv.2:** [의상] 또는 [전화번호 목록] (Hash 문제)
* **LeetCode Medium:** `Top K Frequent Elements` 또는 `Longest Consecutive Sequence`


2. **복기 (20분)**
* 자바 `HashMap`의 `getOrDefault()`, `computeIfAbsent()` 등 코테용 핵심 메서드 패턴 정리.



---

### 10:00 ~ 12:00 (2시간) | [트랙 B] 1일차 이월 작업 완료 & 프로젝트 뼈대 생성

목표: Git 저장소를 정리하고 Spring Boot 프로젝트 뼈대를 올립니다.

1. **1일차 핵심 문서 커밋 (30분 - 미완료 시 진행)**
* GitHub 저장소 생성 (`butter-me-up`)
* `README.md`, `docs/requirements.md`, `docs/architecture/ADR-001-tech-stack.md` 작성 후 커밋.


2. **Spring Boot 프로젝트 스캐폴딩 (1시간 30분)**
* Java 17/21 + Spring Boot 3.x 기반 프로젝트 생성 (Spring Web, Spring Data JPA, Lombok, Validation, Testcontainers).
* Layered / Hexagonal Architecture 패턴 중 본인이 선호하는 패키지 구조 세팅.
* `.claude/skills/code-style/SKILL.md` 파일 생성 (클래스 명명 규칙, 예외 처리 규칙 작성).

### 13:00 ~ 15:00 (2시간) | [트랙 B] 테스트 정책 Agent Skill 작성 & 헬스체크 API 구현

목표: AI가 함부로 테스트를 약화시키지 못하도록 '테스트 정책 Skill'을 만들고 첫 번째 REST API를 구현합니다.

1. **테스트 강제 Agent Skill 작성 (30분)**
* `.claude/skills/testing-policy/SKILL.md` 작성:
```markdown
---
name: testing-policy
description: 테스트 작성 및 검증 시 따라야 할 절대 규칙
---
# 테스트 정책 및 준수 사항

1. 새로운 API/비즈니스 로직 작성 시 ControllerTest / ServiceTest를 반드시 포함한다.
2. existing test files (기존 테스트)를 수정할 경우, 반드시 수정 이유를 커밋 메시지에 명시해야 한다.
3. 테스트 통과를 위한 하드코딩된 mock 응답이나 에러 우회 코드를 금지한다.

```




2. **첫 API 구현 (`/health` & `/api/v1/coaching/ping`) (1시간 30분)**
* Claude Code CLI를 통해 구현 지시:
> `"testing-policy 스킬을 준수하면서, 시스템 상태를 확인하는 /health API와 응답 테스트용 Controller 및 이에 대한 WebMvcTest를 작성해줘."`


* 작성된 코드와 단위 테스트가 깔끔하게 그린(Green) 상태로 통과하는지 확인.

### 15:00 ~ 17:00 (2시간) | [트랙 B] Dockerfile 작성 & 로컬 컨테이너 실행

목표: 애플리케이션을 컨테이너화하여 추후 K8s 배포의 기반을 마련합니다.

1. **Multi-stage Build 적용 `Dockerfile` 작성 (1시간)**
* 그래들 빌드 레이어와 실행 레이어를 분리하여 최적화된 Docker Image 생성.


2. **로컬 실행 및 검증 (45분)**
```bash
docker build -t butter-me-up:v0.1 .
docker run -p 8080:8080 butter-me-up:v0.1
curl http://localhost:8080/health

```


3. **Day 2 최종 Git Commit & Push (15분)**
```bash
git add .
git commit -m "feat: Spring Boot 기본 스캐폴딩, /health API 구현 및 Dockerfile 작성"
git push origin main

```
