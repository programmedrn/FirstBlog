0시부터 23시까지 1시간 단위로 player가 몇 명인지 담겨있는 players[]를 받는다. 서버 하나에 m 명을 감당할 수 있고 서버를 열면 k시간 동안 운영된다. 그래서 각 시간별 필요한 players를 감당하기 위해 서버를 최소 몇 대 더 열어야 하는지 계산하는 문제'

문제를 접하고 서버가 열린 k시간동안 player 수를 떨어뜨리고 시간을 0 부터 23까지 올라가며 탐색하게끔 했다. 사소한 조정에서 오류가 몇 번 있었지만 알고리즘을 바꾸진 않았다.

```java
class Solution {
    public int solution(int[] players, int m, int k) {
        int answer = 0;
        int totalAdded = 0;
        for(int hour=0;hour<24;hour++){
            if(players[hour] > 0){
                int added = (players[hour]) / m;
                for(int i=hour;i<hour+k;i++){
                    if(i < 24) players[i] = players[i] - added * m;
                }
                totalAdded += added;
            }
        }
        
        answer = totalAdded;
        return answer;
    }
}
```
