기본적으로 구간 합을 계산할 때 유용한 방법이다. 누적합 역시 구간합이지만 세그먼트 트리가 필요한 순간은 특정 위치의 값이 변동이 일어나 해당 위치가 포함된 구간합에 변동이 발생할 때이다. 누적합 방식으로 하자면 해당 위치가 연관된 누적 범위를 전부 찾아 업데이트를 해줘야 한다.  
이런 영향을 최소화하기 위해 구간을 잘게 쪼개고, 잘개 쪼개진 구간끼리의 합을 미리 계산해둔다. 예를 들어 [0, 5]의 구간 합에 대해 [0,5] 전체의 구간 합과 [0, 2], [3,5]를, [0,1],[2,2],[3,4],[5,5]를, 다시 그 아래에 각각 [0,0], [1,1], [3,3], [4,4]를 계산해둔 트리를 만든다. 트리의 부모는 항상 그 자식의 구간이 합쳐진 모양새이며 다시 그 잎은 절반씩 쪼갠다고 생각하고 설계한다. 구간합이 필요할 땐 요구된 구간에 대해 노드가 제시하는 합이 범위를 초과하면 쪼개고, 들어가면 자신 값을 반환하는 식으로 해서 재귀적으로 더한다. 또 값의 변화가 발생하면 해당 노드에서 부모로 수정을 전파하면 된다. logN 만큼의 수정과 logN만큼의 탐색이 필요하고, 설계에 N이 발생한다.  
구간이 주어지면 해당 노드를 찾기 위해 실제로 범위를 쪼개면서 내려가면 되고, 노드 번호가 주어지면 해당 노드를 찾기 위해 2진법 변환을 사용하면 된다. 예를 들어 6 = 110인데 이것은 가장 앞이 루트 노드로 1, 그 다음은 1로 오른쪽, 다음은 0으로 왼쪽으로 분기해 내려가면 노드번호 6에 해당하는 노드를 찾을 수 있다.  
또 트리의 전체 노드 수는 대략 최대 4n까지 예비하면 된다. 왜냐하면 logN 이 h라고 하면 마지막 리프 노드로 2^h, 즉 n개의 노드가 준비돼야 하고 그러면 마지막 번호가 2^h부터 2*2^h -1 까지 예비돼 있어야 하는데 N이 항상 2의 거듭제곱꼴이 아닐 수 있기 때문에 최대 2^h < 2n이고 마지막 노드 번호는 2*2^h -1이므로 4n보다는 항상 작다.  
이제 코드로 살펴보자. 전체 배열이 int[] list로 주어지고 길이는 n이라고 하자. 질의와 수정은 적당히 해석할 수 있는 상태라고 가정하고 함수만 마련하자.

```java
public void serarch(int[] list, int n){
  int[] tree = new int[4n];
  build(list, tree, 1, 0, n-1);
}

public void build(int[] list, int[] tree, int now, int start, int end){
  if( start == end) {
    tree[now] = list[start];
    return;
  }
  int mid = (start+end)/2;
  build(list, tree, now*2, start, mid);
  bulid(list, tree, now*2+1, mid+1, end);
  tree[now] = tree[now*2] + tree[now*2+1];
}

public void update(int[] tree, int targetIndex, int newValue, int now, int start, int end){
  if(start==end) {
    tree[now] = newValue;
    return;
  }
  int mid = (start+end)/2;
  if(targetIndex <= mid) update(tree, targetIndex, newValue, now*2, start, mid);
  if(targetIndex > mid) update(tree, targetIndex, newvalue, now*2+1, mid+1, end);
  tree[now] = tree[now*2] + tree[now*2+1];
}

public int query(int[] tree, int queryStart, int queryEnd, int now, int start, int end){
  if(start >= queryStart && end <= queryEnd) return tree[now];
  if(start > queryEnd || end < queryStart) return 0;
  int mid = (start + end)/2;
  return query(tree, queryStart, queryEnd, now*2, start, mid) + query(tree, queryStart, queryEnd, now*2+1, mid+1, end);
}
```

mid가 항상 floor를 계산하는 것과 현재 노드번호에 대한 추적이 항상 필요하다는 점에 주의하자.
