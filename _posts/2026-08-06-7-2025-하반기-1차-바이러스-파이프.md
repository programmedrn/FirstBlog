파이프가 노드 둘을 연결하고 있으며 각 파이프별 타입이 존재한다.  
노드 개수와 파이프 정보가 주어지고 몇 번 파이프를 열고 닫을 수 있는지 주어진다.  
파이프를 한 번 열 때 같은 종류의 파이프 전체가 열린다.  
최초로 감염된 노드가 주어지고 열린 파이프로 연결된 노드는 인접하지 않은 노드까지 모두 오염된다. 그러니까 1--2--3에서 1이 오염상태고 파이프가 열리면 3까지 전파된다.  
단계별 파이프를 한 종류씩 열고 닫았을 때 가장 많은 노드가 감염된 개수를 묻는 문제.

일단 파이프 종류가 3개이고 단계는 최대 10번이므로 3^10은 9^5 정도라 DFS로 무난할 거라 예상했다.  
그래서 함수를 알아보기 쉽게 나눴다.
```java
class Solution {
    
    public int[][] allEdges;
    public int maxStage;
    public int nodeCount;
    public int edgeCount;
    
    public int[] nodeStatus = new int[101];
    public int maxInfection = -1;
    public int edgeLength;
    
    public int solution(int n, int infection, int[][] edges, int k) {
        int answer = 0;
        
        allEdges = edges;
        maxStage = k;
        nodeCount = n;
        edgeCount = edges.length;
        
        edgeLength = allEdges.length;
        nodeStatus[infection] = 1;
        
        onStage(1);
        answer = maxInfection;
        return answer;
    }
    
    public int openEdge(int edgeNum){
        if(nodeStatus[allEdges[edgeNum][0]] == 1 && 
          nodeStatus[allEdges[edgeNum][1]] == 0){
            nodeStatus[allEdges[edgeNum][1]] = 1;
            return allEdges[edgeNum][1];
        }
        if(nodeStatus[allEdges[edgeNum][0]] == 0 && 
          nodeStatus[allEdges[edgeNum][1]] == 1){
            nodeStatus[allEdges[edgeNum][0]] = 1;
            return allEdges[edgeNum][0];
        }
        
        return -1;
    }
    
    public void undoInfection(int[] infected){
        int len = infected.length;
        for(int i=0;i<len;i++){
            if(infected[i] >= 0){
                nodeStatus[infected[i]] = 0;
            }
        }
    }
    
    public int[] infectionOn(int type){
        int[] infected = new int[nodeCount];
        int index = 0;
        
        boolean infectionCheck = true;
        while(infectionCheck){
            infectionCheck = false;
            for(int i=0;i<edgeCount;i++){
                if(allEdges[i][2] == type){
                    int check = openEdge(i);
                    if(check != -1){
                        infected[index++] = check;
                        infectionCheck = true;
                    }
                }
            }
        }
        return infected;
    }
    
    public void onStage(int stage){
        if(stage == maxStage + 1){
            int viruses = 0;
            for(int i=1;i<nodeCount+1; i++){
                if(nodeStatus[i] == 1) viruses++;
            }
            maxInfection = Math.max(maxInfection, viruses);
            return;
        }
        
        int[] infected;
        
        infected = infectionOn(1);
        onStage(stage + 1);
        undoInfection(infected);
        
        infected = infectionOn(2);
        onStage(stage + 1);
        undoInfection(infected);
        
        infected = infectionOn(3);
        onStage(stage + 1);
        undoInfection(infected);
    }
}
```

문제는 두 가지였다.  
첫째로 파이프가 뚫려있으면 끝까지 감염되는 줄 몰랐다. 이건 예제를 꼼꼼히 안 읽어서 그랬다. 코드 적용하기 전에도 살짝 당황했는데 GPT가 while(boolean)으로 관리하고 그냥 반복해서 전체 edge를 훑으라고 추천해줬다. edge가 100개 뿐이라 가능했지만 좋은 코드는 queue를 선언하고 queue가 빌 때까지 감염된 node를 기반으로 업데이트 하는 방식 같다. 이쪽, 그러니까 utility 쪽에 들어있는 queue나 set을 잘 쓰는 법을 연습해야겠다.  
둘째로 node번호를 index로 그대로 쓴 부분이 있고 index로 옮기면서 -1한 부분이 있다. 그러니까 1번 node의 status를 status[0]에 기록하느냐 stauts[1]에 기록하느냐 하는 문제가 있었다. 앞으로는 그냥 직관성을 기준으로 통일해야겠다. 이번에도 1번 node의 상태는 status[1]에 기록하는 것으로 했다.
