격자 지도에서 빗방울이 떨어지는 리스트가 주어지고  
가장 늦게 빗방울을 맞는 지역 찾는 문제

나는 복잡도가 문제가 될 걸 알았지만 코딩 자체의 감이 떨어진 상태라 일단 전체 순회로 구현했다.  
그마저도 알고리즘 자체에서 머릿속에서 몇 번 수정을 거치다 방향성(범위 벗어나면 break할지 안 벗어나면 continue할지)이 꼬여서 몇 번 수정을 거쳐야 했다. 어쨌든 복잡도가 엉망이라 제출은 실패.

**처음 짠 코드는 이렇다**
```java
class Solution {
    public int[] solution(int m, int n, int h, int w, int[][] drops) {
        int[] answer = new int[2];
        
        int chk=0;
        int pnt=0;
        int bestPoint=-1;
        for(int row=0;row<=m-h;row++){
            for(int col=0;col<=n-w;col++){
                chk=0;
                pnt=0;
                for(int[] drop:drops){
                    if(drop[0]<row+h && drop[0]>=row)
                        if(drop[1]<col+w && drop[1]>=col) break;
                    pnt++;
                }
                if(bestPoint < pnt){
                    answer[0] = row;
                    answer[1] = col;
                    bestPoint = pnt;
                }
            }
        }
        return answer;
    }
}
```

찾아보니 슬라이딩 윈도우 덱이라는 게 있었는데  
윈도우 크기가 주어지고 배열이 있을 때, 윈도우가 이동하며 각 구간에서 적정값을 찾는 알고리즘이었다. 그러니까 배열을 O(N) 순회하며 윈도우 크기별 목표하는 값을 찾겠다는 알고리즘.  
이 문제를 푸는 방법은 이걸 세로 한 번, 가로 한 번 수행하여 M-H+1, N-W+1 크기의 새 격자를 만들어내고 각 칸에 윈도우(선인장 구역)이 있을 때 언제 비를 맞게 되는지 알아낸 다음, 가장 늦게 맞는 칸, 그러니까 슬라이딩 윈도우에서 알아낸 최솟값이 가장 큰 구역을 지정하면 되는 것이다. 그 과정에서 정해둔 INFINITE 값과 같은 칸이 있으면 그대로 정지. 그러니까 O(NN) 크기의 복잡도가 된다.  
또 마지막에 정리된 것 중 하나는 위쪽 행이 우선 판정이므로 행에 대한 판단을 마지막으로 미뤄야 한다는 것이다. 그러니까 열에 대해 먼저 판단한 후 행에 대해 다시 판단해야 위쪽 행 우선으로 값을 뽑을 수 있다. 물론 과정을 행/열에 대한 판단값을 다시 쓴 다음 마지막에 전체 최솟값 map을 보면서 판단하면 순서가 상관없지만 메모리, 수행 시간에서 이득을 보려면 마지막에 순회하면서 정답을 쓰는 게 낫기 때문에 이 부분을 좀 더 신경 쓰면 좋다는 것을 알게 됐다.  
알고리즘 자체에서 놀라웠던 부분은 deque를 써서 가장 앞은 최솟값 위치로, 오른쪽은 후보로 유지하는 점이다. 그래서 필요할 때마다 최솟값을 바로 찾을 수 있지만 또한 사용할 값을 뒤쪽에 저장할 수도 있다. 뒤쪽에 넣을 땐 넣는 값보다 큰 값들은 다 치워버리기 때문에 결국 필요한 값들로만 오름차순으로 정렬된 리스트를 얻게 되는 것이다.  
정리한 코드는

```java
import java.util.*;

class Solution {
    public int[] solution(int m, int n, int h, int w, int[][] drops) {
        int[] answer = new int[2];
        int INF=m*n+1;
        
        int[][] grid = new int[m][n];
        for(int i=0;i<m;i++){
            Arrays.fill(grid[i], INF);
        }
        
        int len = drops.length;
        for(int i=0;i<len;i++){
            grid[drops[i][0]][drops[i][1]] = i;
        }
        
        int[][] minColGrid = new int[m-h+1][n];
        for(int col=0;col<n;col++){
            Deque<Integer> deque = new ArrayDeque<>();
            for(int row=0;row<m;row++){
                if(!deque.isEmpty() && deque.peekFirst() <= row - h){
                    deque.pollFirst();
                }
                
                while(!deque.isEmpty() && grid[deque.peekLast()][col] >= grid[row][col]){
                    deque.pollLast();
                }
                deque.addLast(row);
                
                if(row >= h-1){
                    minColGrid[row-h+1][col] = grid[deque.peekFirst()][col];
                }
            }
        }
        
        int firstHit = -1;
        for(int row=0;row<m - h + 1;row++){
            Deque<Integer> deque = new ArrayDeque<>();
            for(int col=0;col<n;col++){
                if(!deque.isEmpty() && deque.peekFirst() <= col - w){
                    deque.pollFirst();
                }
                
                while(!deque.isEmpty() && minColGrid[row][deque.peekLast()] >= minColGrid[row][col]){
                    deque.pollLast();
                }
                deque.addLast(col);
                
                if(col >= w-1){
                    int left = col - w + 1;
                    int hitNow = minColGrid[row][deque.peekFirst()];
                    
                    if(firstHit < hitNow){
                        firstHit = hitNow;
                        answer[0] = row;
                        answer[1] = left;
                    }
                }
            }
        }
        return answer;
    }
}
```
